# 0004: Jednotná značka rodu

Stav: schváleno. Rozhodnutí: Q5.

## Kontext

Název rodu se na webu objevoval jednou se značkou, jindy holý, jednou se slovem „rod“.

## Rozhodnutí

Jedna komponenta: barevný kruh a název. Holý název rodu v textu je zakázán a při sestavení se sám nahradí značkou. V zadání a metodice je pravidlo anonymní a přenositelné.

## Důsledek

Test v sestaveném HTML hlídá holé názvy, barvu a pořadí rodů.
