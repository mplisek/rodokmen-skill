# Úkoly ke směrování (vstup)

Sem se zakládá každý nový úkol (`tools/fronta.py pridej vstup --text …`). Router (orchestrátor) ho pak zařadí:
`fronta.py smeruj <id> --do <fronta> --dod "co je výsledek" [--cena S|M|L|XL]`, rozdělí (`rozdel`) nebo zaparkuje (`zaparkuj`).
Úkol bez definice hotového se nesměruje. Pravidla: `reference/nocni_rezim.md`. Do cílových front se přímo nezakládá.
